Knox Navigator 0.2.4 для Project Zomboid Build 42.21.

**Установка:** скачайте `KnoxNavigatorSetup.exe`, запустите и нажмите **Установить / обновить**. Папка модов выбирается автоматически. Установщик сам загрузит части карты, проверит SHA-256, распакует и установит мод. Python, PowerShell-команды и права администратора не нужны.

После установки включите **Knox Navigator** в меню модов и для своего сохранения. Загрузите мир и сядьте в машину. Игра должна быть закрыта во время установки.

Скачивается около 3,5 ГБ подробных карт. На время установки оставьте 12 ГБ свободного места. Предыдущая установка при обновлении сохраняется рядом с модом в папке `.KnoxNavigator-backup-*`.

Файлы `KnoxNavigator.zip.001` и `.002` загружаются установщиком автоматически. **GitHub Source code ZIP не содержит карты** и не является готовым модом.

В моде: поиск 1647 мест, выбор конкретного объекта, маршруты по дорогам, исчезновение пройденной линии, пересчёт при отклонении, изометрический вид и вид сверху, изменение размера окна, указатель направления и маркеры друзей на сервере.

Изображения и POI: Project Zomboid Map, набор B42.20.2-r1. Дорожная сеть: B42.21. Сторонние данные сохраняют права своих авторов; см. CREDITS.txt. Игра с четырьмя участниками требует дополнительной проверки.
